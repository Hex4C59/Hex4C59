谁负责结束这个 Agent？

比较同一个父 Agent P 与子实例 C。改变调用 Context 和 parentAgent，分别观察资源归属与 Registry 分类。

01 / 创建入口

调用方和登记关系都指向 P

C 的 lifecycle effect 登记在 P.ctx，Registry 的 parentAgent 也指向 P。两种关系一致，各自承担自己的职责。

Registry 记为子实例，资源仍由 root 持有

parentAgent 只进入 Registry 的 owner 字段；它不会把已经登记在 root 的 lifecycle effect 搬到 P 的 Scope。

Registry 列为根，资源仍随 P 的 Scope 退出

资源归属来自调用方 Context；省略 parentAgent 不会抹掉这条 effect 关系，但 Registry 仍把 C 列在 roots 中。

工厂提供者调用方 / Scope共享清理Session
