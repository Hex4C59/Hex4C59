如果你还不会 Rust，可以从这套教材的第一章开始。你不需要事先掌握 C、C++ 或其他编程语言；需要会创建文件、安装软件，并愿意在终端里运行命令。第一章会解释这些命令在做什么。

学完后，你应该能独立创建一个 Rust 项目，处理文本和列表，把代码拆成函数和模块，读懂常见编译错误，并写出一个能够保存数据的命令行工具。这是本教材的入门目标。第十八章会用本机服务介绍 HTTP 请求。异步编程、并发、完整网络服务、`unsafe` 和嵌入式开发留到后续专题；它们各自需要更多练习。

## 先看最后会做出什么

第十一、十二章会实现 `taskbook`，一个在终端使用的待办工具。命令行界面（Command Line Interface，CLI）指用文字命令操作程序的方式。

```sh
cargo run -p taskbook -- add "学习 Rust"
cargo run -p taskbook -- add "写练习"
cargo run -p taskbook -- done 1
cargo run -p taskbook -- list
```

最后一条命令输出：

```text
1 [x] 学习 Rust
2 [ ] 写练习
```

你结束程序、重新运行，它还能读回任务。做出这个工具需要处理用户输入、组织数据、报告错误和读写文件，也需要给这些行为写测试。前十章会逐步准备这些知识。

## 下载源码，建立练习目录

下载 [Rust 从零开始配套源码](/posts/rust-from-zero/course.zip)，解压后会得到一个 `rust-course` 目录。基础工作区有两个 Cargo 包；后续练习另放在 `practice` 和 `projects` 工作区：

```text
rust-course/
├── Cargo.toml             多个包共用的工作区配置
├── README.md              源码使用说明
├── basics/
│   ├── examples/          第 1～10 章示例和练习答案
│   ├── src/               第 8 章模块示例
│   └── tests/             第 8 章集成测试
├── compile-fail/          专门用来观察编译错误的代码
├── taskbook/
│   ├── src/               第 11～12 章项目
│   ├── examples/          第 11 章内存版本
│   └── tests/             命令行集成测试
├── practice/
│   ├── taskbook-plus/     第 13 章功能扩展
│   ├── error-lab/         第 14 章错误类型
│   └── taskbook-json/     第 15 章 JSON 存储
└── projects/
    ├── taskbook-backup/   第 16 章备份与恢复
    ├── taskbook-cli/      第 17 章 clap 命令行
    └── lesson-http/       第 18 章本机 HTTP 请求
```

先按第一章安装工具。之后在终端进入解压出的目录，例如：

```sh
cd rust-course
cargo run -p rust-basics --example ch01_hello
```

`cd` 改变终端当前所在的目录。上面的命令假设终端已经位于 `rust-course` 的上一级；如果不在，请先进入你的下载目录。不要把文件夹路径原样照抄成别人的路径。

教材中所有带 `-p rust-basics` 或 `-p taskbook` 的命令，都在这个 `rust-course` 目录运行。`-p` 选择要运行的包，`--example` 选择示例。这两个基础包只有 Rust 标准库依赖；安装好工具链后，可以给 Cargo 命令加上 `--offline`，避免访问依赖仓库。

## 怎样读一章

先把整段示例运行起来，确认输出。随后读解释和语法细读，写出关键表达式的类型、绑定的作用域，以及移动或借用发生的位置。再给变量换一个值、修改一种写法，预测运行结果或编译错误，最后关掉示例独立做练习。

参考答案放在可展开区域。遇到困难时先看编译器指出的行和错误原因，再对照本章讲过的规则。仅仅把答案运行成功，不能说明你已经能从空文件写出来。

本教材使用两种代码说明：“完整代码”可以按指定命令运行；“局部片段”用来解释某个表达式，需要放到上下文中。明确写着“故意无法编译”的例子用于观察错误，不要用它覆盖正常示例后期待编译成功。

第 13～15 章放在 `rust-course/practice`。它包含功能扩展、错误类型和 JSON 存储三个包，不属于前面的基础工作区。先在这个目录运行 `cargo fetch --locked` 获取练习依赖，再运行带 `-p taskbook-plus`、`-p error-lab` 或 `-p taskbook-json` 的命令。第十五章使用 Serde 和 serde_json，首次获取依赖需要网络；下载包的锁文件固定了本轮使用的版本。

第 16～18 章在 `rust-course/projects` 运行，包含 `taskbook-backup`、`taskbook-cli` 和 `lesson-http`。同样先运行 `cargo fetch --locked`。它们分别练习备份与恢复、clap 参数解析，以及只访问本机服务的 HTTP 请求；不要在外层工作区寻找这些包。

## 怎样检查自己读懂了语法

[语法规则阅读路线](/posts/rust-from-zero/#syntax-route)整理了八个章节的语法细读。它们直接放在原章中，既解释常见写法，也讨论看起来相近却不能互换的写法。初次阅读按章节推进，回顾时按符号或问题查表。

例如看到 `let mut slot: &mut i32`，应分别解释两个 `mut` 约束什么；看到 `Some(wanted)`，应判断它在模式位置绑定了新名字，还是在表达式位置构造值；看到 `?`，应指出包围它的返回类型。仅能复述程序输出，还没有完成这些检查。

每次只改一个地方，例如增加分号、去掉引用、把一个模式名字换成 `_`。先写下预计的类型或错误原因，再运行核对。编译器接受程序，只证明它满足相应的类型和借用等编译规则；输入输出是否符合需求仍需项目练习验证。

## 阶段练习与排错

[分级练习与项目验收](/posts/rust-practice-checkpoints/)安排在第六、十二、十八章之后。每个阶段依次练习修改现有程序、补全行为和独立实现，参考答案放在折叠区域。它们是正式章节之外的附录，不改变前十八章的阅读顺序。

第四章增加了[移动与借用图解](/posts/rust-04-ownership/)，第九章增加了[引用有效范围图解](/posts/rust-09-traits/#生命周期描述引用之间的关系)。遇到工具、工作区、编译或运行错误，可以查[集中排错指南](/posts/rust-troubleshooting/)，再回到对应章节。

## 学习路线与验收

| 阶段 | 章节 | 通过标准 |
| --- | --- | --- |
| 写出基础程序 | 1～3 | 不看答案写出一个计算总时长、判断是否达标的程序 |
| 理解数据的使用 | 4～6 | 能解释移动和借用的区别，定义并修改一个任务列表 |
| 处理错误和组织代码 | 7～10 | 对无效输入返回错误，把逻辑拆成模块并写测试 |
| 完成项目 | 11～12 | 新增、完成、列出任务；重启可读回；出错时给出明确提示 |
| 继续完善项目 | 13～15 | 增加查询和删除，区分错误种类，把旧任务迁移到 JSON 新文件 |
| 文件、命令行与网络 | 16～18 | 恢复到新文件，用 clap 检查参数，区分 HTTP、JSON 与业务失败 |

第四章通常值得多做几遍。你可以在一章上停留几次练习，不必为了赶进度记住所有语法。第九章的生命周期先要求能读懂基本签名、解释引用来自哪里；复杂的泛型接口不在这次入门的验收范围内。

## 编译器报错时怎样继续

运行 `cargo check`，先处理第一条实际的 `error`。找到它指向的文件和行号，再读下面的说明。一个错误可能让后续代码产生更多报错，修好它后重新检查。

如果有 `E0382` 这样的编号，可以运行：

```sh
rustc --explain E0382
```

它会解释对应错误类型。`warning` 是警告，通常不阻止编译，但也值得处理。让人看懂的代码与能通过编译的代码都需要练习。
