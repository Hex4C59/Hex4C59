# Concurrent local-diff review

Python 3.11+. `python app.py` runs an explicitly labelled **fixture** demonstration. It reads `fixtures/demo.diff`, starts logic, security and performance reviewers through the shared runtime, validates their structured findings and renders one report. At most two reviewers run at once by default. The model replies are fixed; they are not evidence of live model review quality.

In the downloaded ZIP, `agent_runtime.py` and pinned `requirements.txt` are included:

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py --trace review.jsonl --report review.md
python -m unittest -v
```

In the repository, install `../common/requirements.txt` and set `PYTHONPATH=../common`. Trace/report paths must not already exist. Without explicit output paths, the report goes to stdout and temporary traces are removed at exit.

The fixture finding refers to an actual added line in the diff. It is not generated by running project tests. The renderer checks JSON shape and exact path/line/evidence, but cannot prove that a model's diagnosis is true or that it found every bug.

## Local input, without GitHub

```sh
python app.py --diff /path/to/change.diff --trace ingest.jsonl
python app.py --git --workspace /path/to/repository --trace worktree.jsonl
python app.py --git --staged --workspace /path/to/repository --trace staged.jsonl
```

These commands work offline. For custom input, fixture reviewers explicitly return “diff ingested; fixed responses do not analyze custom code” with no invented findings. To obtain model analysis, add `--live` after setting both `OPENAI_API_KEY` and a selected `OPENAI_MODEL`. `OPENAI_BASE_URL` is optional. Each live client uses the shared `AsyncOpenAI` adapter and closes after its review. Missing configuration or provider failure is reported; it never falls back to a fixture.

`--git` actually runs a local `git diff` with external diff and text-conversion helpers disabled. It reads working-tree changes to tracked files; `--staged` reads the index. It does not fetch GitHub PRs, invoke `gh`, post comments or include untracked files. Git is bounded by a 5-second deadline and 12,288-byte diff limit. Nonzero exit, oversized output and invalid UTF-8/diff are errors.

Supported input is an ordinary text unified diff with complete hunks and relative paths. Binary-only/combined diffs, quoted path formats and truncated hunks are rejected. Split large changes into separate review inputs. Workers all read the same immutable diff snapshot; this example does not silently mix it with current file contents.

## Structured findings and incomplete results

Each finding must include `path`, `line`, `severity`, `title`, `body` and `evidence`. `severity` is high/medium/low; evidence must exactly match the stripped added line at that position. Unknown fields, wrong types, invented paths/lines, unsupported severity and malformed JSON produce `invalid`, not “no issues.” Findings on unchanged/deleted lines are outside this small tutorial's supported output format.

The supervisor bounds concurrency to 1–4 reviewers, gives each active reviewer a deadline, and bounds its shared loop to 4 turns/3 tools. It uses a semaphore and independent model/message histories; this is not process or OS isolation. Completed findings survive another reviewer's `error`, `invalid`, `timeout`, `limit` or cancellation. The report displays each status and marks the batch `PARTIAL`. Application exit is 1 for partial review, 130 for cancellation, and 2 for input/configuration errors. Exit 0 only means all review outputs passed this application's structural checks.

JSONL traces identify reviewer and run/tool events without storing diff bodies, prompts or credentials. Tests use barriers to prove concurrent overlap and the limit, plus real temporary Git repositories and entrypoint subprocesses. They also verify timeout, cancellation, malformed output, evidence validation and retention of completed findings. No API key is needed, and none of these tests assess live model quality.
