## 项目边界

项目暂名 `rust-webserver`，先用标准库完成教学用 HTTP/1.1 子集。默认绑定 `127.0.0.1`，处理 GET 和 HEAD，每连接一个请求并声明关闭；实现首页、健康检查、与第十八章客户端匹配的课程 JSON，以及文档目录下的静态文件。

请求头的读取有大小和时间上限，路径解析限制在文档目录内，线程池和等待队列均有限额。关闭时停止接收新连接，明确已接收任务的处理策略，并回收工作线程。请求体、长连接、TLS、公网部署和异步框架留在扩展范围；各项协议支持与拒绝策略必须随实现明确记录。

## 底层学习分支

已提供的入门文章是 `/articles/rust-memory-model/`，源码为课程下载包中的 `systems/layout.rs`、`systems/string_move.rs`、`systems/drop_order.rs` 和 `compile-fail/systems-borrow-drop.rs`。它们观察布局、所有权与析构，不把类型大小或编译器重排结果当作稳定 ABI。

后续补充的分支包括：编译与链接、泛型实例化和动态分发、操作系统 I/O、TCP 与 HTTP 消息边界、线程和同步、负载边界，以及项目后的异步状态机与唤醒。容器分配、CPU 缓存和原子内存序逐步展开，不在第一篇内存入门中宣称已经覆盖。

网络实验把确定性的解析器测试和真实 socket 测试分开。单元测试按不同切片边界喂入同一请求；真实连接检查最终字节序列与协议行为，不依赖一次写入恰好对应一次读取。性能实验记录数据、构建模式、输入、并发与统计方法；观察结果和规范保证分别说明。
