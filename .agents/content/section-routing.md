# 内容归类与系列规则

适用于新建、续写、调整归属和整理标签的任务。先判断内容的主题、来源与阅读关系，再选择模板。顶层导航提供稳定的浏览入口，不随写作主题变化。

## 存放位置与导航

- 新文章默认放在 `content/articles/<slug>/index.md`，图片、图表和下载资源放在同一目录。
- 顶层入口为首页、文章、系列、关于，配置在 `data/navigation.toml`。分类、搜索、标签、归档和 RSS 是辅助入口。
- `content/agent/`、`content/tutorials/`、`content/posts/`、`content/translations/` 保留已发布文章及兼容入口。继续编辑这些文章时保留目录、公开网址和资源位置；不要为改变分类迁移正文。
- `data/sections.toml` 登记正文目录的收录和兼容页面行为，不承担主题分类。新主题统一使用文章目录，无需新增源目录或页面模板。
- 文章可以从分类、标签、系列、搜索等入口访问，正文只保存一份。内部 Agent 指令继续放在 `.agents/`。

## 判断与填写顺序

1. 用一句话明确文章主要讨论什么，选择 `data/categories.toml` 中对应的主题键作为 `categories`。通常选择一个主要主题；确实同时讨论两个主题时可以补充第二个。不要按来源、是否有代码或标题是否含“教程”决定主题。
2. 填写 `source_kind`。原创使用 `original`，忠实翻译或沿原作转述使用 `translation`；来源定义在 `data/article_sources.toml`。译文填写原文标题、URL、作者和网站，不因翻译而改变主题。
3. 按实际内容选择可选的 `article_type`，定义在 `data/article_types.toml`。讲解、操作、复盘、评测与随笔是文章形式，不是主题。没有合适形式时可以暂不填写，再按持续需求扩展配置。
4. 填写少量具体标签。每篇最多 3 个，通常 2—3 个，选择正文实际涉及的概念、工具、作品或地点。中文概念优先使用标准中文名；Rust、MCP 等通用名称保留原写法。不重复添加“教程”“译文”等来源或形式标签。
5. 确认是否属于系列，再填写系列关系。独立文章不用填写系列角色和排序。

已有标签中的同义词归并到一个标准名称，并为历史标签地址保留别名跳转。相关但不同的概念不能仅因名称接近而合并。新增标签前先查已有标签和文章，避免大小写、单复数及中英文同义词重复。

## 新增主题与扩展形式

出现现有主题无法合理收录的内容时，在 `data/categories.toml` 增加稳定的键、显示名称、说明和顺序，再将该键填写到文章中。例如新增旅行内容可以添加 `travel`，文章仍放在 `content/articles/`。分类页、筛选项和首页主题入口由内容与配置生成，不修改模板，也不提前建立没有文章的分类。

主题键与显示名称分开维护。改名时优先只调整显示名称；必须改变已有主题键时保留旧分类地址。文章形式、来源、系列类型和角色分别在对应数据文件中扩展。学习难度、公式与代码功能按文章需要填写，不要求非技术文章提供技术字段。

讨论 Agent 机制或实践时再读取 [Agent 内容约定](agent-section.md)；技术内容同时应用 [技术写作规范](technical-writing.md)。DeepSeek Harness 的专项规则和规划继续按根文件的任务路由读取。

## 系列成员与阅读顺序

系列说明放在 `content/series/<key>/_index.md`；成员文章使用同一个 `series` 键，不要求放在同一源目录。

- 开放合集没有必填排序，默认按最近更新展示。需要固定顺序时，给参与排序的所有正文填写唯一的非负整数 `series_order`。
- 连续阅读系列设置一个 `series_index = true`、`layout = "series"` 的目录文章。目录只属于一个系列，每个系列最多一个目录文章，至少有一个阅读页。目录正文用于介绍和列出阅读资料。
- 阅读成员使用 `series_role = "guide"` 或 `"chapter"`，按 `series_order` 排列；正式章号使用唯一的正整数 `series_number`。导读可以不填写章号。
- 练习使用 `series_role = "exercise"`，参考资料使用 `"appendix"`。它们填写相同的 `series`，不填写 `series_order` 和 `series_number`，不参与正文翻页。
- 文章可加入多个开放合集，最多加入一个连续阅读系列。成员角色定义在 `data/series_roles.toml`，是否参与顺序由 `in_sequence` 控制。
- 目录文章的 `series_kind` 定义在 `data/series_kinds.toml`。课程、译文合集与普通有序系列共用阅读布局；开放合集可以在系列说明页设置类型。
- `series_start` 通过 `site.GetPage` 查找源路径，例如 `/tutorials/rust-00-learning-guide/`。连续系列的起点必须是阅读成员，不能指向附录。正文链接使用公开地址。

首页与文章列表默认把连续系列合并到目录入口，更新日期包含所有成员。文章列表可以展开成员；标签页默认展开，方便找到具体知识点。搜索和归档保留所有已发布成员。

## 已发布内容与检查

调整元数据时保留文章的 `url`、图片与下载地址、正文锚点和评论关联。不要把历史地址中的 `posts`、`translations` 等前缀当作当前主题。

检查主题、来源、形式、标签与系列角色是否准确；正文编号不受附录影响；新主题是否能只通过配置和内容出现。程序检查未知主题和字段、译文来源、重复排序、错误起点、失效链接及资源；内容是否适合某个主题仍由编辑判断。

构建与发布按 [Hugo 发布规范](../hugo-publishing.md) 执行。修改规则时检查引用路径，不扩大正在进行的其他内容任务。
