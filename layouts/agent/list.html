推荐学习路径

如果你准备长期写 Agent 内容，页面最好不仅能展示文章，还能承担“导航”和“路线图”的作用。下面这三条路径分别对应入门认知、系统设计与实践落地。

01

入门认知

先建立整体框架，理解 Agent 到底是什么、解决什么问题，以及它和普通聊天机器人、固定工作流之间的区别。

  • 什么是 Agent
  • Agent vs Workflow
  • 最小可用 Agent 的组成
  • Tool Use / ReAct / Planning 基本概念
02

系统设计

当你开始真正搭建 Agent，就会遇到上下文边界、状态流转、工具约束、记忆设计与评测方式等工程问题。

  • Prompt 与上下文管理
  • 工具调用与错误恢复
  • 短期记忆与长期记忆
  • 规划、反思与评测机制
03

实践落地

最后再看真实案例，重点关注一个 Agent 为什么可用、哪里会失败，以及如何在成本、稳定性和效果之间做平衡。

  • Coding Agent
  • Browser Agent
  • Research / RAG Agent
  • Multi-Agent 协作

主题地图

如果你不是按时间顺序读文章，而是想按主题集中看内容，可以优先从下面这些方向切入。

Concepts

理解 Agent 的基本定义、常见范式和边界问题。

agent workflow react reflection

Core Components

围绕模型、提示词、工具、记忆、规划与状态管理建立系统结构。

prompt tools memory planning

Engineering

关注可观测性、调试、评测、成本、稳定性和失败恢复这些真正决定可用性的细节。

eval debugging safety latency

Use Cases

通过具体案例理解不同 Agent 形态如何落地，以及不同场景下的取舍逻辑。

coding browser research multi-agent
